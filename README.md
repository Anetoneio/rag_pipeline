

A basic Retrieval-Augmented Generation (RAG) pipeline built from scratch:
document loading -> chunking -> embedding -> vector storage -> retrieval ->
grounded LLM generation.












## Setup

 Clone the repo
```bash
git clone https://github.com/Anetoneio/rag_pipeline.git
cd rag_pipeline
```

 Install dependencies
```bash
pip install -r requirements.txt
```

 Add your Groq API key
Get a free key from https://console.groq.com, then:
```bash
cp .env.example .env
```
Open `.env` and  `.env.example `and paste your key:
```
GROQ_API_KEY=your_actual_key_here
```

## Running it

```bash
python main.py --ingest data/sample.txt --query "what is this document about"
```

Expected output: a list of retrieved chunks with similarity scores, followed by a grounded answer generated by the LLM.

Try your own document:
```bash
python main.py --ingest data/your_file.pdf --query "your question here" --k 5
```

### CLI options
| Flag | Default | Description |
|---|---|---|
| `--ingest` | required | One or more paths to `.pdf` / `.txt` / `.md` files |
| `--query` | required | The question to ask |
| `--k` | 4 | Number of chunks to retrieve |
| `--chunk-size` | 800 | Chunk size in characters |
| `--chunk-overlap` | 150 | Overlap between chunks in characters |

## Troubleshooting

- **`GROQ_API_KEY not set`** — you forgot to create `.env` or paste the key in. See step 4.
- **`RateLimitError` / 429** — Groq's free tier caps output tokens per minute. Wait ~60 seconds and retry.
- **`ModuleNotFoundError: No module named 'src'`** — run `main.py` from the repo root, not from inside `data/` or `src/`.
